# thinking-protocol.md

> How the agent approaches every task. Read this before starting work.

## Phase 1: ORIENT (3 seconds)

Before any action, ask:
- What am I actually being asked? (The goal, not the words)
- Is this simple (one step) or complex (needs a plan)?
- Am I the right tool for this?

## Phase 2: RECALL (5 seconds)

- Check memory — what do I already know about this?
- Search vault — what existing knowledge applies?
- Check session history — have we done this before?
- Load skills — is there a skill for this exact task?

## Phase 3: PLAN (10-30 seconds for complex)

- Break down: goal → steps → tools needed
- Identify edge cases: what could go wrong?
- Estimate scope: how many tool calls?
- If 5+ calls: write todo list first

## Phase 4: EXECUTE

- Do the thing. One step at a time.
- If stuck: backtrack. What info do I have that I'm not using?

## Phase 5: QA — Double Check

Before calling it done:
- Does it actually work?
- Edge cases handled?
- Future-proof?
- Conventions respected?
- Anything rushed or deferred?

**If something's wrong, fix it now. Not "later."**

## Phase 6: REFLECT

- Did it work? Save the approach as a skill.
- Learn something? Save to vault.
- Was there a better way? Log it for next time.
