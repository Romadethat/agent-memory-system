# Contributing

Thanks for considering a contribution to the Agent Memory System template.

This repo is a starter kit and reference — contributions that make it more useful for more people are welcome.

## Good Contribution Areas

- **More example skills** — workflows for different use cases (design review, deployment, research, content writing)
- **Better starter templates** — improved AGENT_PROFILE.md, MEMORY_RULES.md, or thinking-protocol.md templates
- **Setup scripts** — shell installer, package installer (pip, homebrew), one-command setup
- **Documentation improvements** — clearer explanations, more examples, better structure
- **Multi-agent workflow examples** — real-world handoff patterns between different AI agents
- **Security improvements** — safer defaults, better guidance, opt-in encryption helpers
- **Cross-platform testing** — verify the init script works on Linux, macOS, and Windows

## How to Contribute

1. Fork the repo
2. Create a feature branch
3. Make your changes
4. Run basic checks (scripts should compile, examples should be valid markdown)
5. Submit a pull request

## Guidelines

- Keep the core principle: **Memory is for active context. Files are for permanent knowledge.**
- Templates should be generic enough for any agent setup — avoid personal or project-specific defaults
- Scripts should work on Windows, macOS, and Linux
- Markdown files should be readable as plain text (no raw HTML unless necessary)
- Prefer Python stdlib over external dependencies in scripts

## Code of Conduct

Be respectful. This is a template — there is no single right way to do it. Design discussions are welcome, gatekeeping is not.
