# Project Handoff — Skill

## When to Use
When switching projects or passing work to another agent.

## Workflow
1. Update project-state.md with current completion status
2. Log what's been done and what's remaining
3. Drop a bridge relay to the receiving agent or your future self

## Bridge Relay Format

```md
# [P0-HANDOFF] Subject

**From:** sender
**To:** recipient
**Date:** YYYY-MM-DD

## Done
- [Completed items]

## Pending
- [Remaining items]

## Context
- [Files involved]
- [Key decisions]
- [Gotchas to know]
```
