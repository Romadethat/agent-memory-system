# Daily Summary — Skill

## When to Use
At end of every session to log what happened.

## Workflow
1. Summarize what was built, fixed, learned
2. Save to logs/daily/YYYY-MM-DD.md
3. Update project-state.md with current status
4. Commit any pending thoughts to vault/ or ideas/

## Template

```md
## Session: YYYY-MM-DD HH:MM

### Built
- [What was built]

### Fixed
- [What was fixed]

### Learned
- [What was learned]

### Next
- [What to do next]
```
